# 나의 할 일 목록

HTML, CSS, JavaScript만으로 만든 할 일(Todo) 관리 웹 앱입니다. 별도의 설치나 빌드 과정 없이 브라우저에서 바로 실행됩니다.

## 주요 기능

- **할 일 추가**: 내용을 입력하고 `추가` 버튼이나 Enter 키로 등록합니다.
- **날짜 지정**: 📅 버튼으로 할 일의 날짜를 고릅니다. 기본값은 오늘입니다.
- **완료 표시**: 체크박스로 완료/미완료를 바꿉니다.
- **삭제**: 항목별 `삭제` 버튼, 또는 `완료된 항목 삭제`로 완료 항목을 한 번에 지웁니다.
- **날짜별 보기**: 할 일 옆의 날짜를 누르거나 달력에서 날짜를 고르면 그 날짜의 할 일만 보여 줍니다. `전체 보기`로 해제합니다.
- **상태 필터**: `전체` / `진행중` / `완료` 탭으로 목록을 거릅니다.
- **개수 표시**: 현재 보고 있는 날짜 범위의 전체·완료 개수를 보여 줍니다.
- **중복 방지**: 같은 날짜에 같은 내용의 할 일은 다시 등록되지 않습니다.
- **자동 저장**: 할 일은 브라우저의 LocalStorage에 저장되어 새로고침해도 유지됩니다.

## 실행 방법

1. 저장소를 내려받습니다.
   ```
   git clone https://github.com/KImJooni/Todofirst.git
   ```
2. `index.html` 파일을 브라우저로 엽니다. 서버는 필요 없습니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 화면 구조 |
| `style.css` | 화면 스타일 |
| `main.js` | 할 일 상태 관리, 화면 그리기, LocalStorage 저장 |

## 참고

- 데이터는 사용 중인 브라우저에만 저장됩니다. 다른 브라우저나 기기와는 공유되지 않습니다.
